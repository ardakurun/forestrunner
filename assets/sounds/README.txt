SOUND EFFECTS
=============
Drop sound files here (.ogg, .wav or .mp3) with these names:

  jump, double_jump, slide, land, hit, game_over,
  menu_move, menu_select, milestone, pause

Example: jump.wav. Any sound without a file uses a small generated beep.
Turn the beeps off with USE_PLACEHOLDER_SOUNDS = False in settings.py.
Volume: SFX_VOLUME in settings.py.
